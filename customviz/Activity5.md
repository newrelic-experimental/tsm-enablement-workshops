# Activity 5: Publish and Deploy Your Visualization

## What You Will Learn
- How to build, publish, and subscribe to your visualization
- How to add your visualization to a New Relic dashboard
- Best practices for publishing

## Exercises

### 1. Build and Publish
```bash
cd /workspace/my-nerdpack
nr1 nerdpack:build
nr1 nerdpack:publish
nr1 nerdpack:subscribe
```

### 2. Add to Dashboard
- Go to New Relic Dashboards
- Click "Add widget" → "Custom visualizations"
- Select your published visualization
- Configure NRQL queries and properties

- You added it to a dashboard and learned best practices
